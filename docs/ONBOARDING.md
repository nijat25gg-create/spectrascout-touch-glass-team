# Гайд команды SpectraScout

Всё в одном месте: `docs/team-hub.html` (открыть в браузере двойным кликом). Контракты: `contracts/README.md`.

**Команда:** Ниджат (CS 1, капитан, LLM-модуль), Семён (CS 2, бэкенд), Ярик (CS 3, движок правил), Гаджи (CS 4, фронт и PDF), Никита (химик).

## Два правила

1. **Код решения пишем с 16.10, 18:00.** До старта учимся, готовим знания, кейсы и договорённости. Учебный код держим у себя, не в репо. Всё подготовленное заранее записываем в `DECLARATIONS.md`.
2. **Никто никого не ждёт.** Для каждого контракта есть пример в `contracts/examples/`: фронт рисует `C8_briefing.example.json`, бэкенд отдаёт примеры как заглушки, пока чужая часть не готова.

## Ответы на вопросы с созвона

- **Контракт** это договорённость о форме данных при одной передаче между частями. Их 8 на основной проход (C1–C8) плюс C1b для пересчёта и E для ошибок. Всё в `contracts/`.
- **Извлечение параметров** происходит внутри LLM, но вызывает её бэкенд. Фронт шлёт только строку.
- **В LLM уходят** три вещи: инструкция (промпт от CS 1), текст клиента, схема ответа. Обратно приходит JSON.
- **Баллы методов** считает обычный код CS 3 по правилам химика, без LLM.
- **Свою модель не тренируем.** Берём Claude через API по ключу. «Научить» = инструкция + примеры + схема + карточки знаний.
- **Проверка входа** (не пусто, длина, язык) на бэкенде у CS 2. **Оценка методов** у CS 3.

## Путь одного запроса

1. Гаджи (фронт) → Семён (бэкенд): **C1** `text`, `language`.
2. Семён проверяет вход, при ошибке отвечает **E**.
3. Семён → Ниджат: **C2**, шаг А. Ниджат → Семён: **C3**, 16 параметров и 12 признаков.
4. Семён → Ярик: **C4**, признаки. Ярик → Семён: **C5**, баллы и отказы.
5. Семён → Ниджат: **C6**, шаг Б. Ниджат → Семён: **C7**, вопросы, объяснения, эксперимент, риски.
6. Семён → Гаджи: **C8**, готовый брифинг.
7. Пересчёт: Гаджи → Семён **C1b**, шаг А пропускается, дальше снова C4 → C8.

## Роли коротко

**Ниджат · CS 1 · капитан.** Промпты шагов А и Б, контракт, координация, видео, сдача. Учить: Claude API `messages.parse`, Pydantic.

**Семён · CS 2 · бэкенд.** Python + FastAPI. Учить: FastAPI First Steps, Request Body, Pydantic, Claude quickstart, CORS (для POST нужен `allow_methods`). Не учить: Docker, базы данных, React. Упражнение у себя: `POST /echo`, ошибка 400 при тексте короче 20 символов, проверка в `/docs`.

**Ярик · CS 3 · правила и оценка.** `rules.yaml` + `score_methods`, отброшенные методы с причиной, скрипт «совпало X из Y». Учить: Python словари, PyYAML, CSV. Вторник после 16:30: созвон с CS 2 и химиком.

**Гаджи · CS 4 · фронт и PDF.** Обычный HTML + CSS + JS, без React. Учить: `fetch()`, вывод JSON через шаблонные строки, `@media print`. PDF: `window.print()` + стили печати, без библиотек.

**Никита · химик.** Правила для CS 3, 30–50 кейсов в CSV, проверка карточек, проверка ответов на хакатоне, 30 секунд в видео. Учить ничего технического не нужно.
