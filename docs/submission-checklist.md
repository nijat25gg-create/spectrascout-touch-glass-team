# Submission checklist

Official deadline: Sun 18.10, 23:59. Our deadline: Sun 18.10, 22:00.

## Required

- [ ] Team details in the submission form
- [ ] Project summary in English
- [ ] Repository (or archive) at the right commit
- [ ] README explains what the project is and how to run it
- [ ] Demo video in English, max. 5 minutes
- [ ] Declarations: code, models, datasets and AI tools ([DECLARATIONS.md](../DECLARATIONS.md))
- [ ] Artifacts required by the AFS challenge brief
- [ ] Jury has access to the project for 90 days

## Final checks

- [ ] Video is under 5 minutes and the audio is clear
- [ ] `main` is on the commit we want to submit
- [ ] Demo link opens on a device outside the team
- [ ] Repository visibility is set so the jury can open it
- [ ] No secrets in the repository history
