# Demo video script (max. 5 minutes, English)

Built around one live customer case.

| Time | Part | Who | Content |
|---|---|---|---|
| 0:00–0:20 | Hook and team | Captain | Team name and the five roles on screen. |
| 0:20–0:50 | The problem | Captain | A short real customer request on screen. A customer writes three sentences; the expert has to work out what is missing, which method to test first and why. |
| 0:50–3:20 | Live demo | Frontend on screen, captain speaks | Paste request → parameters with status → questions → methods with scores and rejected methods with reasons → answer one question, recommendation updates → first experiment → PDF. |
| 3:20–3:50 | Expert voice | Chemist | How the rules were written and checked, and why the assistant always shows its reasoning. |
| 3:50–4:20 | Numbers | Rules engine | Match with the expected method on N cases, share of missing information found, stability across runs. |
| 4:20–4:45 | How it works | Captain | One architecture slide: code scores, the LLM understands and explains. |
| 4:45–5:00 | What's next | Captain | AFS experts can extend the rules themselves and collect expert feedback. |
