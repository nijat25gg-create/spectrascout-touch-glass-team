8 контрактов основного прохода и 2 служебных

Контракт это правило рукопожатия между двумя частями: какие поля передаются и какие значения допустимы. Данные каждый раз разные, форма всегда одна. Источник правды: contracts/models.py, проверка: python contracts/check_contracts.py.

Почему 8, а не 16 стрелок

Контракт нужен только там, где данные переходят из одной части в другую. Проверка входа внутри бэкенда (стрелка 3) и действия эксперта в интерфейсе (1, 11, 12) контрактами не являются.

Как работает LLM без обучения

Свою модель не тренируем. Используем Claude через API по ключу. «Научить» модель значит дать ей хорошую инструкцию, схему ответа и знания. Каждый шаг LLM это один вызов из четырёх частей.

1 · system

Инструкция

Кто ты, что делать, чего не делать: «не придумывай значения, нет данных → unknown». Пишет Ниджат.

2 · messages

Данные

Шаг А: текст клиента. Шаг Б: параметры, признаки и результат движка.

3 · output_format

Схема ответа

Контракт C3 или C7. Claude обязан вернуть JSON именно такой формы.

4 · контекст

Знания

Только для шага Б: карточки методов из материалов AFS и слой экспертов. Объяснения только по ним, со ссылкой.

Так выглядит шаг А в Python

Иллюстрация для понимания. Рабочий код пишем на хакатоне.

import anthropic
from contracts.models import ExtractInput, Extraction

client = anthropic.Anthropic()            # ключ из ANTHROPIC_API_KEY

def extract(inp: ExtractInput) -> Extraction:          # C2 -> C3
    resp = client.messages.parse(
        model="claude-sonnet-5-5",
        max_tokens=4000,
        system=EXTRACT_PROMPT,                          # инструкция Ниджата
        messages=[{"role": "user", "content": inp.text}],
        output_format=Extraction,                       # контракт C3
    )
    return resp.parsed_output

Почему два шага, а не один

У структурированного вывода Claude есть лимиты на сложность схемы. Маленькие схемы C3 и C7 укладываются, это проверено скриптом.

Почему без живого поиска статей

Поиск по вебу в Claude API всегда возвращает цитаты, а цитаты несовместимы со структурированным JSON-ответом. Поэтому поиск возможен только отдельной кнопкой после брифинга, и только если останется время.

Модели

claude-sonnet-5-5 для ответов, claude-haiku-5-5 для дешёвых тестов. Ключ только в .env, в репо никогда.
