## Факт = значение + единица/категория + источник + статус

Каждое свойство в `assessment_b.facts` хранится так: `value`, `unit_or_category`, `source`, `quote`, `status`.
Статусы: `reported` (сообщил клиент, есть цитата), `inferred` (выведено), `unknown`, `confirmed_experiment`, `confirmed_expert`, `conflicting`.
Все поля каталога выводятся всегда, пустые со статусом `unknown`, поэтому отсутствие данных видно, а не выдумано.
В покрытие (coverage → confidence) идут только `reported` и `confirmed_*`, `inferred` никогда.
Неизвестный статус на входе = ошибка данных, а не догадка.

## Как считает (по spec)

- Правило → MATCH / MISMATCH / UNKNOWN / NOT_APPLICABLE. UNKNOWN = 0 в сумме, но хранит возможные эффекты → интервал.
- Группа: сумма, обрезка [-3, 3]. raw_Q = сумма 4 групп. Score_Q = bucket_10_v1_proposed (0–9).
- suitability = Q1 + Q1b + Q2 + Q3 (0–36). Q4 (0–3) отдельно, только в confidence.
- exclusive_group: берётся самая специфичная строка, без двойного учёта.
- Исключение только hard-предикатом с источником и известными фактами (метод / пара / сборка).
- Чувствительность: каждый неизвестный факт перебирается по домену; меняет лидера (метод) или исключения → high, меняет топ-3 → medium. До 3 вопросов.

## Переключатели

- `ENGINE=a` только gates. `ENGINE=ab` gates решают, результат B лежит в `assessment_b`. `ENGINE=b` (по умолчанию, решение 18.10 20:30) B решает `ranked/rejected`.
- `B_RANK_MODE=technical` (по умолчанию, решение команды 18.10): `critical_unknown` только пометка и основание для вопроса, не первый ключ сортировки. `B_RANK_MODE=spec`: буквальный ключ 06 §5.
- В каждом Case есть `headline`, например: «NIR and Raman lead (24/36); provisional until 'optical properties fluorescence' is checked.»

## Решение команды 18.10: critical_unknown — пометка, не первый ключ

`critical_unknown` первым ключом поднимает кандидатов, о которых ничего не известно. Пример D01 (порошок, API): в режиме spec первым идёт MIR «surface diffuse reflection» (23), а NIR diffuse reflection и Raman probe (24) уходят вниз только потому, что у них неизвестно «можно ли касаться продукта». В режиме technical: NIR, Raman, MIR ATR — как в 07 §5. Приёмка D/H проходит в technical.
